# Workshop Prompts: Student Dashboard Project

These are the prompts used in today's workshop to build, deploy, and share the Student Dashboard.

### 1. Project Conception
> "I would like to demo how I can create files and for this workshop why not a Student dashboard that I can work on locally and see in my web browser then later push it up to github so I can see or share it with others."

### 2. Refining the Tech Stack (Node.js/Vite)
> "Does this use python? Many of the students don't have that, can we keep it to just using node?"

### 3. GitHub Integration
> "Lets get this setup to push to my remote repo now."
> "My info: https://github.com/ggriffin924/class-workshop.git please set this up and then publish the current files to that remote repo."

### 4. Live Deployment (GitHub Pages)
> "Great it published, I would like to have github be able to show a webpage with my project."

---

### **Quick Reference Commands:**
- **Start Local Server:** `npm run dev`
- **Build Project:** `npm run build`
- **Deploy Updates:** `npm run deploy`
